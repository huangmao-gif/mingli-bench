# 规则表 v2 修订提案

v1 是线上提示词规则的忠实实现，用来证明问题、作为对照。v2 是在 v1 基础上的**修订提案**，目标是解决 v1 的三个结构性问题，同时尽量不改动原有的人物设定。

**状态：提案，待产品负责人审核。** 产品后端默认仍用 v1（`MINGLI_RULES=v2` 才启用）。

## 一、人物匹配

### 1. 核心条件与辅助条件分层

每条规则拆成两部分：

- **核心条件**：原文第一个逗号之前的星曜组合，比如「紫微+七杀/破军」；
- **辅助条件**：其余部分，比如「化权入命或迁移」。

选人物时先比「核心条件是否全部满足」，再比整体满足率，然后比条件数，最后比编号。理由是星曜组合决定了人物的基本气质，辅助条件只用来区分细节。v1 按整体比例排序，一个核心组合都不沾边、只碰巧满足几条辅助条件的人物也可能被选中。

各条规则的核心条件数见 `src/persona.ts` 中的 `CORE_COUNTS`。

### 2. 刘备

| | 条件 |
|---|---|
| v1 原文 | 紫微+天同/太阴化科，兄弟或交友宫旺 |
| v1 的问题 | 紫微与天同、太阴不可能同在三方四正（证明见 `docs/RULES.md` 第三节），永远无法完全满足 |
| v2 提案 | **核心**：天同或太阴化科坐命宫或身宫；左辅或右弼在命宫三方四正（人和）。**辅助**：兄弟或交友宫旺 |

第一版提案用的是「天同或太阴化科在三方四正」，300 张盘试跑时刘备占了 16%，远高于 24 人的平均（约 4%），所以收紧为「坐命或身」。

## 二、六维分

### v1 的问题

v1 要「主星庙旺**且**化禄/化科同宫」才加 2 分，而负面信号覆盖面很宽：化忌和四煞坐宫、化忌冲照、四煞在对宫、空劫坐宫、化忌在三合宫都扣分。正面信号远少于负面，所以整体偏低。

### v2 规则（单宫，以 3 为基准）

| 方向 | 信号 | 分值 |
|---|---|---|
| 正面（累加，最多 +2） | 本宫有化禄、化权或化科 | +1 |
| | 本宫有六吉或禄存 | +1 |
| | 主星庙旺，**且本宫没有任何负面信号**（庙旺无煞） | +1 |
| 负面（累加，最多 −2） | 四煞坐宫 | −1 |
| | 化忌坐宫 | −1 |
| | 空劫坐宫 | −1 |
| | 化忌在对宫冲照 | −1 |

多宫维度仍取平均，恰好 .5 时向 3 靠拢，与 v1 相同。

### 选型依据

在 2,000 张盘上比较了 5 个候选方案（脚本思路同 `scripts/simulate.ts`）。所有维度合并统计：

| 方案 | 1 分 | 2 分 | 3 分 | 4 分 | 5 分 | 均值 |
|---|---|---|---|---|---|---|
| A 庙旺+1 化+1 辅+1 ｜ 煞、忌、空劫、对宫忌各 −1 | 1.1% | 6.7% | 48.4% | 36.4% | 7.4% | 3.42 |
| B 庙旺且化 +2 / 化 +1、辅 +1 ｜ 同 A | 1.8% | 12.7% | 61.2% | 20.6% | 3.6% | 3.12 |
| **C 化 +1、辅 +1、庙旺无煞 +1 ｜ 同 A（采用）** | 1.8% | 12.7% | 50.7% | 27.5% | 7.4% | 3.26 |
| D 同 B ｜ 再加对宫四煞 −1 | 2.6% | 21.6% | 61.4% | 12.3% | 2.1% | 2.90 |
| E 同 A ｜ 再加对宫四煞 −1 | 1.6% | 11.3% | 59.6% | 23.3% | 4.2% | 3.17 |

采用 C：均值接近 3，5 分与 4 分有足够比例，同时「庙旺无煞」符合「主星得地而不受冲破才算吉」的读法。如果希望分数更集中、更保守，可以改用 B（均值 3.12，61% 落在 3 分）。

## 四、需要你决定的事

1. 核心/辅助的分层方式是否认可，各条的核心条件数是否合适。
2. 刘备的新条件是否符合你对这个人物的设定。
3. 六维分采用方案 C 还是 B，或者另定。
4. 是否要进一步平衡人物分布：v2 下仍有人物极少被选中（见上表）。可以逐条放宽，也可以接受不均匀，但这是产品判断。
