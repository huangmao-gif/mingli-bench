# 判定规则与原提示词的解读

引擎把命理鉴心产品提示词里的两段规则（`SCORES_RUBRIC` 六维打分锚点、`PERSONA_MAPPING` 24 人物映射）改写成代码。原文是写给 LLM 的自然语言，有不少歧义，下面逐条列出这里采用的解读。**这些是可以讨论的设计决定，不是唯一正确答案**；改动时同步改测试。

## 一、六维分（`src/scores.ts`）

### 维度 → 宫位（原文照搬）

| 维度 | 宫位 |
|---|---|
| 自我觉察 | 命宫 + 身宫（身命同宫时只算一次） |
| 情绪调节 | 福德 |
| 延迟满足 | 财帛 + 官禄 |
| 关系模式 | 夫妻 + 交友 |
| 不确定性容忍 | 迁移 |
| 自我叙事 | 命宫 + 福德 |

### 单宫打分

以 3 为基准，正面最多 +2，负面最多 −2，结果截断到 1–5。只有一侧有信号时，恰好落在原文的 5 个锚点上。

| 原文锚点 | 本实现的判定 | 调整 |
|---|---|---|
| 5：主星庙旺 + 化禄/化科直接落入 | 本宫有庙或旺的主星，**且**本宫有任意星化禄或化科 | +2 |
| 4：辅星正面支持（昌曲/魁钺/禄存/左右） | 本宫有其中任意一颗（不看亮度） | +1 |
| 1：化忌或火铃羊陀直接冲坐 | 化忌坐本宫；化忌在对宫（冲）；四煞坐本宫 | −2 |
| 2：煞星干扰或化忌波及 | 空劫坐本宫；四煞在对宫；化忌在三合宫 | −1 |
| 3：无显著信号 | 以上都没有 | 0 |

**解读取舍**

- 「冲」只用于化忌：化忌在对宫算强负面，四煞在对宫算弱负面。否则命宫加对宫 4 个位置覆盖 5 颗以上的凶星，几乎每个维度都会是 1 分。
- 正负同时出现时相互抵消。原文没有规定优先级。
- 化权不计分，原文锚点没有提到它。
- 多宫维度取平均；恰好 .5 时向 3 靠拢，对应原文「不确定时一律给 3 分」。

## 二、24 人物（`src/persona.ts`）

### 通用解读规则

1. **「X+Y」表示 X 和 Y 都出现在命宫三方四正**（命宫、迁移、财帛、官禄），不要求同宫。理由见第三节：按同宫解读，有 5 条规则在任何命盘上都不可能成立。
2. **「庙旺」「化X」只修饰紧邻的前一颗星**。例如「武曲+天府/天相庙旺」：武曲在，加上天府或天相之一庙旺。
3. 原文写明宫位的（如「福德有陀罗」「擎羊在命或福德」），只看那几个宫。
4. **宫旺**：至少一颗主星庙或旺。**命弱**：无主星，或主星全部为平、不、陷。
5. 「煞」统一指六煞：擎羊、陀罗、火星、铃星、地空、地劫。

### 个别条文

| 人物 | 原文 | 解读 |
|---|---|---|
| 赵云 | 无煞冲破 | 命宫、迁移都没有六煞 |
| 吕布 | 贪狼+火星/铃星化禄 | 火星、铃星不会化禄，所以「化禄」挂在贪狼上 |
| 吕布 | 夫妻宫见桃花星煞 | 夫妻宫同时有桃花星（贪狼、廉贞、红鸾、天喜、咸池、天姚）和煞星 |
| 孙权 | 太阴/天府三方拱 | 太阴或天府在迁移、财帛、官禄 |
| 孙策 | 疾厄见化忌冲照 | 化忌在疾厄或疾厄的对宫 |
| 陈宫 | 交友宫化忌冲照 | 化忌在交友或其对宫（兄弟） |
| 黄忠 | 疾厄长生/帝旺 | 疾厄宫的长生十二神为长生或帝旺 |
| 甘宁 | 命疾厄皆旺 | 命宫、疾厄都是宫旺 |

### 选择规则

按「满足条件数 ÷ 条件总数」排序；比例相同，条件更多（更具体）的优先；再相同，编号小的优先。一定会返回一个人物，同时返回 `fullMatch` 和未满足的条件，产品侧可以据此决定文案措辞。

## 三、原规则表本身的问题（由 `npm run simulate` 发现）

样本为 21,600 张命盘，详见 [`results/SIMULATION.md`](../results/SIMULATION.md)。

### 1. 刘备一条在任何命盘上都不可能完全满足（可证明）

条件要求紫微和「天同或太阴（化科）」同在命宫三方四正。

- 设紫微在地支位置 z（寅=0，卯=1……丑=11）。天府与紫微关于寅申轴对称，在 (−z) mod 12；太阴紧随天府，在 (1 − z) mod 12；天同在紫微逆数第 5 位，在 (z − 5) mod 12。（用样例盘核对：紫微午 z=4 → 天府戌 8、太阴亥 9、天同丑 11，与 iztro 排盘一致。）
- 紫微与太阴的位置差为 2z − 1，与天同的位置差为 5，都是奇数。
- 三方四正内任意两个位置的差只能是 0、4、6、8，都是偶数。
- 所以三方四正内不可能同时出现紫微与太阴，也不可能同时出现紫微与天同。

模拟结果一致：完全满足 0 次。产品上线以来，被判为「刘备」的用户全部是勉强匹配。

### 2. 按「同宫」解读，5 条规则不可能成立

赵云（七杀+天相）、刘备、贾诩（巨门+天机+陀罗）、孙策（七杀+破军）、鲁肃（天同+天机）。这些星曜组合在紫微斗数的安星规则下永远不会同宫。原提示词要求 LLM「严格对照、不可自行发挥」，但这些条件本身无法满足，模型只能自己发挥。

### 3. 只有约三分之一的命盘能完全匹配某个人物

最终选中人物为完全匹配的比例是 32.89%，其余约三分之二的用户拿到的是部分匹配。原提示词承诺「保证同一命盘在任何档位标签一致」，在交给 LLM 自由选择的情况下，这一点没有保证。

### 4. 六维分整体偏低

按原锚点判定，5 分极少（各维度 0%–2.6%），1–2 分占三到六成。「关系模式」和「自我叙事」在样本中从未出现 5 分。原因是负面信号（煞星、化忌及其冲照）在盘面上远比「庙旺主星 + 化禄/化科同宫」常见。如果产品希望分数分布居中，需要调整锚点，而不是让 LLM 在打分时偏宽。
