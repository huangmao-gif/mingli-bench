# LLM 评测结果

模型：请求 `deepseek-chat`，服务端实际返回 `deepseek-flash`。共 60 份报告（10 张盘 × 2 组 × 3 次）。参数与线上一致：只设 max_tokens=4000，不设 temperature / seed。

- **baseline**：线上精简报告提示词，LLM 自己打六维分、选人物，输出 SCORES/CARD 标记。
- **engine**：同样的报告结构，六维分与人物由确定性引擎给出，LLM 只写解读。

## 1. baseline：格式合规与一致性

| 指标 | 结果 |
|---|---|
| SCORES/CARD 严格合规（各一个、合法 JSON、6 维 1-5、人物在表内） | 96.7%（29/30） |
| 同一张盘 3 次生成，人物完全一致 | 40.0%（4/10 张盘） |
| 同一张盘多次生成，六维分完全一致 | 0.0%（0/10） |
| 同一张盘两次生成之间，单维分平均相差 | 0.43 分 |
| 人物与引擎一致（部分匹配的盘上可能有并列，仅供参考） | 10.3% |
| 单维分与引擎完全一致 | 35.0%，平均相差 0.82 分 |
| 在存在完全匹配人物的 4 张盘上，LLM 选中完全匹配人物 | **16.7%**（2/12；引擎 4/4） |
| LLM 所选人物按规则表完全满足的比例（全部盘） | 6.9% |
| LLM 所选人物的平均条件满足率 | 46.6% |

## 2. engine：LLM 是否遵守给定结果

| 指标 | 结果 |
|---|---|
| 正文提到引擎给出的人物 | 96.7% |
| 正文提到其他人物（可能是改人物，也可能只是对比，需人工看） | 6.7% |
| 违规输出 SCORES/CARD 标记 | 0.0% |

## 3. 引用校验：正文里的盘面陈述是否与命盘一致

| 陈述类型 | baseline 错误率 | engine 错误率 |
|---|---|---|
| 某星在某宫 | 0.0%（0/98） | 0.6%（1/176） |
| 生年四化 | 0.4%（1/238） | 0.0%（0/272） |
| 星曜亮度 | 0.6%（3/525） | 0.2%（1/448） |

校验器是正则启发式，会漏抽，也可能误判；所有被判错的陈述列在 [`llm/flagged-deepseek-chat.md`](llm/flagged-deepseek-chat.md)，可逐条人工复核。
