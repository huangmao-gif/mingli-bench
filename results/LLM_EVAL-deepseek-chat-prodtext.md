# LLM 评测结果

模型：请求 `deepseek-chat-prodtext`，服务端实际返回 `deepseek-flash`。共 30 份报告（10 张盘 × 2 组 × 3 次）。参数与线上一致：只设 max_tokens=4000，不设 temperature / seed。

- **baseline（线上复现）**：线上免费档提示词 + 线上前端的命盘文本（无亮度、杂曜、大限），LLM 自己打六维分、选人物，输出 SCORES/CARD 标记。
- **engine**：同样的报告结构，六维分与人物由确定性引擎给出，LLM 只写解读。

## 1. baseline：格式合规与一致性

| 指标 | 结果 |
|---|---|
| SCORES/CARD 严格合规（各一个、合法 JSON、6 维 1-5、人物在表内） | 96.7%（29/30） |
| 同一张盘 3 次生成，人物完全一致 | 60.0%（6/10 张盘） |
| 同一张盘多次生成，六维分完全一致 | 0.0%（0/10） |
| 同一张盘两次生成之间，单维分平均相差 | 0.36 分 |
| 人物与引擎一致（部分匹配的盘上可能有并列，仅供参考） | 16.7% |
| 单维分与引擎完全一致 | 21.8%，平均相差 1.01 分 |
| 在存在完全匹配人物的 4 张盘上，LLM 选中完全匹配人物 | **25.0%**（3/12；引擎 4/4） |
| LLM 所选人物按规则表完全满足的比例（全部盘） | 10.0% |
| LLM 所选人物的平均条件满足率 | 52.5% |
