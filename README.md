# MingLi-Bench · LLM 领域推理评测

针对垂直领域结构化推理任务（命理排盘与人格分析）的 LLM 评测：比较不同大模型在同一输入下的输出质量，并用回归用例兜住 AI 生成代码的计算正确性。

> 起因：作者独立开发的 AI 人格分析与付费问答平台需要选定线上模型与提示词；平台已于 2026-11 停运，本仓库保留评测部分。

## 评分口径（设计稿，权重在评测前固定）

1. **格式合规**：是否合法 JSON、字段是否齐全（硬门槛，不合规记 0）
2. **字段正确性**：关键字段与领域规则是否一致（历法换算、节气边界、大运起运等）
3. **推理一致性**：同一输入多次请求是否给出同一结论
4. **可解释性**：结论是否有可追溯的依据字段

## 回归测试与代码审计

- 审核 AI 生成的排盘代码，依据领域规则识别 **4 处底层数据 / 算法错误**，判定为代码缺陷而非模型理解偏差——这类问题仅凭报错日志无法定位，必须用领域知识反推正确输出。
- 回归用例对照文墨天机验证四柱、节气边界、大运起运三类核心计算。

## 局限

- 单一垂直领域，结论不能外推到通用任务。
- 多模型对比为单盘、网页版手工执行，样本量为 1，只能看定性差异，不能给排名。
- 固定题集与自动打分尚未落地。
